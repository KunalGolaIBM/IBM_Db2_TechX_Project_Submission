# Required screenshots

Capture these from your own running project after `/api/health` confirms `db2: true` and `storage_mode: "db2"`:

1. `01-health-db2.png` — browser or API client showing the successful Db2 health response.
2. `02-companion-profile.png` — profile preferences saved successfully (hide personal information).
3. `03-reminder-persisted.png` — reminder visible after refreshing the page.
4. `04-agent-chat.png` — one successful LangGraph/LangChain chat exchange (hide private content).
5. `05-architecture.png` — the Architecture page showing the system flow.

Do not include `.env`, API keys, passwords, database credentials, or real health information.
