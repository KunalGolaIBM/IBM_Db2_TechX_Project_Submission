# Sample dataset

`sample/breast_cancer_wdbc.csv` is the Wisconsin Diagnostic Breast Cancer dataset (569 rows, 30 numeric features plus a binary `target` column), exported from scikit-learn's bundled copy.

- Source: Dr. William H. Wolberg, W. Nick Street and Olvi L. Mangasarian, UCI Machine Learning Repository, "Breast Cancer Wisconsin (Diagnostic)".
- Licence: CC BY 4.0 (attribution required; see the UCI page for the current terms).
- Contains no patient identifiers; features are computed from digitised images of fine-needle aspirates.
- In `target`, as encoded by scikit-learn, 0 = malignant and 1 = benign.

To try the app, upload this file on the Datasets page and enter `target` as the target column.

Do not upload real patient data to a shared or public deployment.
