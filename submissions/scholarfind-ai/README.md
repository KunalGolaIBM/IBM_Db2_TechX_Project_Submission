# ScholarFind AI

A scholarship discovery platform that helps students find opportunities matching their profiles.

## Technologies
- React
- Vite
- Python FastAPI
- IBM Db2
- ibm_db

## Features
- Scholarship discovery
- Student profile matching
- Scholarship eligibility filtering

## Setup
Install backend dependencies with:
pip install -r src/backend/requirements.txt

Install frontend dependencies with:
npm install

Configure Db2 connection settings before using live database functionality.

## Status
Prototype under development. Db2 connectivity and deployment require configuration and testing.
