[db2-ai-cookbook](https://github.com/IBM/db2-ai-cookbook) and kept identical to the branch proposed there:
[JustJay7/db2-ai-cookbook, `add-temporal-search`](https://github.com/JustJay7/db2-ai-cookbook/tree/add-temporal-search/09-temporal-search).

so they resolve there, not in this repository. The recipe itself runs from here as it is: see
[python-local-embeddings/README.md](09-temporal-search/python-local-embeddings/README.md).
