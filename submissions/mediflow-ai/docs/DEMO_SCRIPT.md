# Three-minute demo

1. Start Streamlit in demo mode and point out that the data source is synthetic.
2. Show on-hand stock, daily usage, days of cover, supplier lead time and expiry.
3. Run the assessment and explain a flagged item using its displayed evidence.
4. Review the draft quantity and the assumptions used.
5. Approve or reject the draft using a reviewer name.
6. Explain that demo review state is process-local; the Db2 path persists recommendations and review events.
7. Show `src/db/schema.sql` and `architecture.md`.

Do not claim that a real hospital is connected or that a supplier purchase order is placed.
