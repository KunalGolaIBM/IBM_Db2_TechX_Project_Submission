# CyberAware AI

An Intelligent Cybersecurity Awareness and Education Platform.

## About
CyberAware AI helps people identify online scams, phishing messages, fake links and fraudulent activities.

## Features
- Cybersecurity educational lessons.
- Interactive cybersecurity quizzes.
- AI-powered cybersecurity assistant.
- Scam awareness and prevention tips.
- IBM Db2 database integration.

## Technologies
- Python
- Flask
- IBM Db2
- LangChain
- Ollama
- HTML, CSS and JavaScript

## Project Structure

- app.py: Flask application.
- ai.py: AI assistant.
- db.py: IBM Db2 connection.
- lessons.py: Lesson retrieval.
- quiz.py: Quiz functionality.
- database/schema.sql: Database structure.
- templates/index.html: Website interface.
- tests/test_app.py: Automated tests.
