🛡️ Db2Hack Guardrail Architecture & Security Rules

To guarantee zero risk to production government data, all natural language queries pass through a multi-tier deterministic validation pipeline before reaching the Db2 query compiler:

  • Read-Only Enforcement: Query must start with SELECT. Keywords like INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, MERGE, CALL, EXEC are rejected immediately.
  • Injection Prevention: Semicolons (statement chaining) and SQL comments (--, /* */) are banned.
  • Table Whitelisting: Access is restricted strictly to departments, grievances, and grievance_updates. Access to catalog tables (e.g. SYSCAT) is blocked.
  • Dialect Compliance: Postgres/MySQL LIMIT is converted to Db2-native FETCH FIRST N ROWS ONLY.
